# 共有リポジトリモデル
## モデルの概要
共有リポジトリモデルとはGit及びGithubを用いてチーム開発を行うための手段である。
メンバーは１つの共有リポジトリへのプッシュアクセス権を持ち、変更が必要なときにトピックブランチを作成する。
プル要求は、変更がメイン開発ブランチにマージされる前にコードレビューと一連の変更に関する一般的なディスカッションを開始するため、このモデルで役立ちます。
このモデルは、プライベートプロジェクトで共同作業を行う小規模なチームや組織で一般的に扱われる。
